# 背景シーン素材（差し替えガイド）

このフォルダの `*.svg` は**仮素材（イラスト調プレースホルダー）**です。
GPT Image 2.0 で生成した本番イラストに差し替えてください。

## 差し替え手順（超かんたん）
1. GPT Image 2.0 で各シーンを生成（下の仕様・プロンプト参照）
2. `public/bg/{シーン名}.png` として保存（例: `public/bg/ground.png`）
3. `src/ui/scenes.ts` の `const BG_EXT = '.svg'` を **`'.png'`** に変更
   - これで全シーンが一括でPNGに切り替わります
   - 一部だけ差し替えたい場合は `scenes.ts` の `SCENE_FILE` を編集

## 共通仕様（全シーン共通）
- **比率**: 16:9 の横長（推奨 1920×1080 または 1600×900）
- **スタイル**: イラスト調・明るい昼・やわらかいパステル（栄冠ナイン的な温かみ）。フラット〜軽いグラデ。
- **重要**: 画面はクリーム色の半透明フレームの**背後に薄く敷かれる**ため、
  - 中央〜全体は**ごちゃつかせない**（人物・文字・ロゴは入れない）
  - 主役はUI。背景は**脇役**として淡く、コントラスト控えめに。
- **禁止**: 実在の学校/スタジアム/ロゴ/人物・既存ゲームの模写・文字。すべてオリジナルの一般的風景。
